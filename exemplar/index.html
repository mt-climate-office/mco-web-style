Mesonet Station Map

mco-web-style exemplar · reference implementation

What this is

A live map of the Montana Mesonet stations, and the reference implementation of the MCO house style — every convention in HOUSE-STYLE.md, composed in one small real app. Copy the exemplar/ directory to start a new map.

Using the map

  • Click a dot for station details; hover for a quick readout.
  • Keyboard: use the Fly to a station picker — every station is reachable without a pointer.
  • Toggle sub-networks with the HydroMet / AgriMet buttons.
  • The URL always holds your full view — copy it (or press Share) to hand someone exactly this map.

Data

Station metadata from the Montana Mesonet API. Boundaries from the US Census (via the kit's map/data/). Basemap © CARTO, © OpenStreetMap contributors.
